❓ R2 桶参数获取教程

全程在 Cloudflare 控制台操作：dash.cloudflare.com ↗
① Account ID（账号 ID）
登录 Cloudflare 控制台 → 左侧「R2 对象存储」→ 概述页右侧「帐户详情」面板 → 复制帐户 ID。填入后 endpoint 会自动拼好，不用手动填。
打开 R2 概述页 ↗
② Access Key ID / Secret Access Key
R2 概述页 → 右上角「管理 R2 API 令牌」→「创建 API 令牌」→ 权限选对象读和写，范围选「仅应用于特定桶」并勾选你的桶 → 创建后页面会显示两串值。Secret 只显示这一次，立即复制保存！
打开 API 令牌管理 ↗
③ bucket（R2 桶名）
R2 →「概述」→「创建存储桶」时起的名字（已建好的话直接点进桶查看名称）。一个账号可以建多个桶，每个桶在这里算一条记录。
查看我的桶列表 ↗
④ 公开访问域名 public_base_url（推荐配置）
进入你的桶 →「设置」→「公共访问」：方式 A 点允许访问开启 r2.dev 子域，复制形如 https://pub-xxxx.r2.dev 的地址；方式 B 绑定自定义域名（需域名托管在同一 CF 账号）。复制到这里，图片直链就走这个域名。
官方文档：公共桶设置 ↗
⑤ 名称 label / 自定义 endpoint / Path Style
label 是你自己起的唯一代号（如 acc01、acc02），用于轮询分发和短链展示；endpoint 留空即可自动按 Account ID 拼 R2 地址（只有接 MinIO 等其他 S3 才需要填）；Path Style 保持默认「是」。
💡 批量接入大量账号时，不需要一个个填表单——用下方「批量导入」的行格式粘贴更快，字段顺序与上面一致。
